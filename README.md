# CineVault

A movie recommendation chat app, built as my capstone for FlyRank's AI Fluency program. You type what you're in the mood for, and it streams back real movie recommendations from Claude.

**Live demo:** https://cinevault-smoky.vercel.app
**Demo video:** https://youtu.be/SFdaReSGf1g

## Who it's for

Anyone who wants to describe what they want to watch in plain language ("something like Interstellar but shorter") instead of scrolling filters. This repo also serves as proof of applied AI-fluency work for reviewers — a small, real, tested AI feature rather than a demo that only works on the happy path.

## Scope decision (read this first)

The original plan for this capstone included a 3D browsing view and a full Playwright end-to-end suite. I cut both. With limited time left before the deadline, I chose to ship one thing that actually works — a streaming chat with real tests and a real deployed URL — instead of a wider feature set with pieces that don't work reliably. That's the "one design decision" for my demo video.

## What's actually built

- **Streaming chat** — real streaming responses from the Anthropic API (`app/api/chat/route.ts`), not a canned/mock reply
- **A system prompt with a guardrail against hallucination** — the model is explicitly told not to invent movie titles, and to say so when it isn't confident (see `lib/prompt.ts`)
- **Unit tests** (Vitest) covering the message-formatting logic that feeds the API — `npm run test`
- **Basic accessibility** — labeled input, `role="alert"` on errors, keyboard-operable form, no reliance on color alone

## What's NOT built (be upfront about this)

- No 3D browsing view (was in the original plan, cut for time — see Scope decision above)
- No Playwright end-to-end tests yet — only unit tests on the formatting logic
- No movie database/poster images — recommendations are text-only, generated by the model directly
- No conversation persistence — refreshing the page clears the chat

## Setup (a stranger should be able to follow this)

Prerequisites: Node 18+, npm, an Anthropic API key.

```bash
git clone https://github.com/abanob24/cinevault.git
cd cinevault
npm install
cp .env.example .env.local
```

Add your key to `.env.local`:
```
ANTHROPIC_API_KEY=your_key_here
```

Run it:
```bash
npm run dev
```

Open http://localhost:3000. Type a request like *"recommend a sci-fi movie like Interstellar, under 2 hours"* and watch the response stream in.

## Eval results (v1)

See `EVAL_TEMPLATE.md` for the manual eval — 10-12 real queries tested against the live app, pass/fail on: does it recommend real movies, is the recommendation relevant, does it handle the "movie that doesn't exist" edge case honestly instead of hallucinating.

**Result: 12/12 passed.** All recommendations were real movies, relevant to the query, and both queries designed to trigger the hallucination guardrail (a fake actor name and a fake movie title) were handled honestly — the model declined to invent a match instead of guessing. For v2, I'd still add a lightweight verified-movie lookup rather than relying solely on the system prompt guardrail, since a 12-query manual eval doesn't guarantee it holds up at scale.

## Known limitations

- No 3D view or e2e tests (see Scope decision above — cut deliberately, not accidentally missed)
- No persistence — chat history is lost on refresh
- Recommendations are model-generated, not pulled from a verified movie database, so accuracy depends entirely on the hallucination guardrail in the system prompt holding up
